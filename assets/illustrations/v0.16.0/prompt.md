# Regular print-screen footer

The built-in Imagegen tool created a smooth grayscale source plate. The previous illustration was used only as a spacecraft and composition reference. Its irregular speckles were not retained.

The website uses a new code-native SVG print screen, generated by [build-footer-halftone.cjs](../../../tools/build-footer-halftone.cjs). Every circle center lies on the same four-unit rectangular lattice; tone changes the circle radius, never the center position or density. The SVG contains exactly two inks and no embedded bitmap. The grid and circle count are recorded in [halftone-grid.json](../../../docs/review/v0.16.0/halftone-grid.json).

- Imagegen source plate: [odin-mountain-grayscale-source.png](./odin-mountain-grayscale-source.png)
- Delivery illustration: [odin-mountain-footer-v0.16.0.svg](../../../public/images/odin-mountain-footer-v0.16.0.svg)
- Source tool: built-in Imagegen; final print screen: deterministic canvas sampling and SVG geometry.

Exact generation prompt:

Use case: stylized-concept. Asset: smooth grayscale source illustration for a dark website footer. Input image is a reference for the Odin starship's identity and overall panoramic composition, NOT a texture to preserve. Create a new very wide panorama (around 3:1) of the Anvil Odin starship hovering in a valley surrounded by layered alpine mountain peaks. Preserve the distinctive long wedge-shaped hull, central raised bridge tower, broad side hangar structure, bow and stern identity from the supplied reference. Put the recognizable starship in the central lower half, slightly above the valley, with a good amount of dark open sky above the silhouette. Mountains form a landscape across the lower two thirds, with layered lighter distant mountains and darker foreground peaks. Medium: carefully rendered smooth black-and-white tonal illustration, like a grayscale plate before a newspaper print screen is applied. Black / charcoal background and subtle off-white grayscale forms. Clean smooth tones and clear edges. IMPORTANT: NO dots, NO halftone, NO stippling, NO noise, NO scratches, NO pockmarks, NO skin-like textures, NO speckles, NO words, NO logos, NO lights that look like stars. Final halftone grid will be generated deterministically in code afterward. Keep it cinematic but quiet, and make the starship technically plausible and faithful to the reference. Very wide footer banner, no UI or text.
