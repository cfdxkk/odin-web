# 主炮收纳间隙核验

最终 v0.8.2 的高精度 GLB 与 Nuxt/Three.js 动作生成了 101 个姿态（展开参数 0.00–1.00，步长 0.01）。对正式可编辑模型复核后，炮管与固定船壳、相邻炮管及新增顶盖接触的阻断事件为 **0**。详见 [完整报告](bore-clearance.json)。此结果包含完整伸缩管和前部卡箍；护甲本身的运动检查另见该版本护甲报告。

| 核验项 | v0.8.1 基线 | v0.8.2 |
| --- | ---: | ---: |
| 管身与固定船壳接触事件（部件 × 姿态） | 96 | 0 |
| 背部中炮收起时与顶盖的采样间隙 | 10.731 | 0.503 |
| 腹部中炮收起时与顶盖的采样间隙 | 10.702 | 0.573 |

间隙数值均为 `Odin_Asset` 的源模型坐标单位。背部左右炮向内收 1.6，腹部左右炮向内收 2.4，并保持到调平完成后才恢复展开间距。这样修复了腹部抬平阶段及背部中段的固定船壳擦碰；三根炮管仍同步伸缩，中炮保持更靠近顶盖的收纳高度。

## 原模型的嵌套安装面

原始炮膛、套筒后段与罩壳之间存在嵌套安装面，完全展开端保持原有几何和姿态。报告将源坐标 Y < 107（背部）或 Y < 57（腹部）的后膛附件单独列出；跨越这一边界的三角面仍纳入前部检查。前部检查中位于罩壳前缘之后的套筒/卡箍接触，也完整记录其部件、姿态和交叉范围。

最终记录了 **489 个罩壳内套接事件**，其中 354 个在基线的相同姿态已有接触，135 个的接触时刻随新的收纳路径改变。另有 **13 个原有腹部中心导轨贴盖事件**；其祖先关节姿态和交叉范围均与基线一致。只有满足这一严格比对的旧导轨接触才被保留。这些记录不构成“所有几何零相交”的结论。

基线 [101 姿态](baseline/v0.8.1-clearance-poses.json) 已使用 Git 标签 `v0.8.1-rc.1` 中的 GLB 和动作程序重新计算，结果逐项完全一致；标签提交及文件校验值见 [基线报告](baseline/v0.8.1-bore-clearance.json)。

## 采样局限与复现

三角网格交叉按 101 个离散姿态检查，不是连续碰撞证明，也不检测完全包覆而没有表面交叉的实体。顶盖间隙采用双向顶点到三角面的最近距离，是精确最小间隙的上界；仍需结合近照和动画观察接缝。候选报告中的校验值对应最终 Blend、GLB、动作程序及姿态文件。
