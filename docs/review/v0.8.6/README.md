# v0.8.6 主炮装甲闭合接缝

修正背部主炮装甲沿船头方向逐渐变宽的接缝，并收紧后侧小盖板下沿露出红色舱底的开口。

原模型的锯齿外沿同时有横向、纵向和高度变化。新版按原网格的齿尖与齿根对应关系拟合主装甲边缘；前端小装甲保持独立，与主装甲共用实际横向接合轮廓。后侧小盖板保持原倾斜平面，重新求取它与固定船壳相接的外沿。

真正的内部表面仍为深红色。固定船壳、腹部机构和所有炮管动作保持；原始 `odin.blend` 不变。动画继续由 Nuxt/Three.js 驱动，导出的 GLB 不含动画片段。

为了保留更紧密的接缝，静态模型的位置压缩精度从 16 位提高到 18 位。

前端小盖板重建为平顺的斜面，保留独立关节、中脊、锯齿边和深红色内面；旧密网格上随变形形成的细竖折纹已移除。最前两段齿口增加贴合固定接收面的浅止口，消除连续透红，保留正常的细装配间距。
