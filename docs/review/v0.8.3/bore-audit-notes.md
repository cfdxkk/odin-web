# 主炮与顶盖同步核验

最终 v0.8.3 高精度 GLB 和实际 Nuxt/Three.js 动作生成的 **101 个姿态**（展开参数 0–1，步长 0.01）已在正式 Blend 中复核。完整伸缩管、前部卡箍与固定船壳、相邻炮管及顶盖之间的新增外露交叉事件为 **0**。详见 [完整报告](bore-clearance.json)。五块舱口装甲的检查由本版本护甲报告单独覆盖。

## 同步与间隙

中炮的套筒、后膛和顶盖保持完全展开时的刚体相对关系；伸缩管仍沿自身轴线运动。两侧炮在主要行程跟随各自顶盖，盖板停止后才完成短距离下沉。腹部左右顶盖的原始名称与物理左右方向相反，核验按实际配对处理。

- 运行时测试检查 **1001 个姿态**及反向跳转：中炮相对顶盖的变换恒定；两侧炮在共同运动阶段保持同样约束。中炮管身中点、前段和顶盖支点均无向船体回落或向船尾反向移动；侧炮最后下沉为固定姿态的直线运动。此结论来自 `tests/rig.test.mjs` 的对应测试，本轮全套 23 项测试通过。
- 背部中炮总成与顶盖的端点采样间隙均为 **0.228341** 源坐标单位。腹部为约 **0.00005**，它对应原模型已有内导轨接触，不能解释为正间隙保证。套筒与顶盖固定关系消除了旧动作中先远离再靠近顶盖的变化；旧版背部/腹部采样间隙在中途曾增至 3.903/3.764，见 [旧间隙曲线](baseline/v0.8.2-center-gap-curve.json)。
- 六根伸缩管统一使用 **20** 的轴向行程；原候选的 16 行程在腹部中段产生固定船壳擦碰，改为 20 后正式 101 姿态检查为零。完全展开的所有主炮世界变换保持 v0.8.2，其他系统的动作也由基线测试核对。

## 保留并明确记录的内嵌接头

报告保留 **569 个罩壳内部套接事件**：493 个在基线相同姿态已有接触，76 个随收纳时序改变。源坐标 Y < 107（背部）或 Y < 57（腹部）的后膛附件独立记录；跨越边界的三角面仍纳入前部检查。完整伸缩管始终参与检查。只有位于罩壳前缘之后、属于原套筒/炮膛嵌套关系的交叉才归入安装面；固定船壳接触不按此豁免。

腹部中心导轨与 `odin.015` 的原有接触从基线 **13 个姿态（0.88–1）**变为 **101 个姿态（0–1）**，因为该总成现在全程保持原完全展开端的相对关系。校验比较同一对网格的完整顶点/三角面指纹、盖板坐标系中的刚体相对变换及局部接触范围，并非按名称直接忽略。几何指纹一致；最大相对变换位移为 **0.0000191**（阈值 0.00005），局部交叉范围最大数值偏差 **0.00432**（阈值 0.005）。后一误差来自近共面的浅接触对浮点舍入的放大。原局部交叉范围为 `[-0.39943, 36.75558, 1.88360]` 至 `[-0.38985, 36.81573, 1.89305]`，见 [完全展开接头基线](baseline/v0.8.2-deployed-interfaces.json)。这些接触没有被宣称为几何零相交。

## 追溯与局限

v0.8.2 的原运行时、101 姿态和报告在改动前已归档，版本为 `v0.8.2-rc.1`，提交 `e19266d61e97ed3a0bf047bd5d17960ddd472bba`，见 [基线来源](baseline/v0.8.2-runtime-provenance.json)。最终报告保存并核对了本版 Blend、GLB、动作程序和姿态文件的 SHA-256。几何指纹忽略材质索引，允许本轮深红内壁材质调整，但不允许顶点或三角面变化。

101 个离散姿态不构成连续碰撞证明；表面交叉检查不检测完全包覆而无表面交叉的实体。双向顶点到三角面的最近距离是精确最小距离的上界。上述数值全部使用 `Odin_Asset` 源坐标单位，仍须结合预览观察接缝和动作。

