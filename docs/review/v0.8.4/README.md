# v0.8.4 前部装甲内侧补色

本轮补齐用户截图中主炮舱前部仍为灰色的固定斜舱壁（`holo.001`），以及左右、腹部对应内壁（`holo.013`），沿用现有深红色内部材质。之前的补色覆盖了活动盖板和炮塔壳体，遗漏了这部分固定舱壁。

保留 v0.8.3 的炮管与护罩同步动画。选择范围限定为主炮开孔内、朝向舱内且能从腔体内直接看见的侧壁面。只调整材质分面；几何、UV、关节、炮管行程、外部涂装和原始 `odin.blend` 均保持。新版可编辑文件为 `assets/blender/odin_articulated_v0.8.4.blend`，导出 GLB 不含动画片段。

## 验证

- 背部 74 面、腹部 114 面补红。全场景 411 个对象的几何、UV、静态变换、层级和关节属性保持；目标之外的面材质保持。详见 `interior-materials.json`。
- `npm test`（23 项）、`npm run verify:asset`、`npm run generate` 通过，高低两份 GLB 均为零动画片段。
- 浏览器实际 WebGL 视图检查前部内壁为深红、船体外侧为灰色，无警告或错误。主炮、副炮、PDC、舰桥机构、尾舱门的动作代码与静态关节未改动。
- 预览由实际 JS 计算的 101 个姿态渲染，MP4 完整解码通过，高清近景取 62% 展开姿态。
